Questions

Does my page content get uploaded?

No. The analysis runs inside the page's tab and the result stays in extension storage on your device. The only outbound call is the license check with Polar, which sends your key and a device label — never page data.

Can it check a staging site behind a login?

Yes, as long as you can open it in Chrome. LaunchLint audits the page you are signed in to, which is exactly the case hosted audit tools usually cannot handle.

Is this another SEO audit tool?

It overlaps on purpose — a page that cannot be indexed or read is a page that failed — but the point is the handoff. Placeholders, dead links, broken images and leftover noindex are the checks that stop a launch, and they come first here.

What happens when the license server is down?

A successful license check is honoured for seven days offline, so a network problem never locks you out of a tool that runs locally.
